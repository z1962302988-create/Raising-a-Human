# 第一天任务：它为什么不肯起床？

## 任务卡

- **任务 ID**：`main_day01_get_out_of_bed`
- **类型**：主线 / 新手引导 / 第一天
- **地点**：共居公寓
- **前置条件**：完成开场接收 H-071
- **核心问题**：人类已经醒来，为什么仍然不肯离开床？
- **叙事目标**：教玩家先观察、再干预；建立“照顾不是催促”的第一层认知。
- **玩法目标**：完成观察、社区、商店、装修、行为反馈和发帖闭环。

## 开场状态

清晨，刚被带回家的 H-071 蜷缩在床上。窗帘紧闭，房间只有旧床、空纸箱、充电中的手机、过亮顶灯，以及一张没有椅子的桌子。它醒来看了一眼手机，又缩回被子。

| 状态 | 初始值 |
| --- | ---: |
| 饥饿 | 35 |
| 疲劳 | 40 |
| 压力 | 55 |
| 安全感 | 20 |
| 幸福指数 | 12 |
| 对猫咪的信任 | 5 |

行为循环：躲在被子里 → 查看手机 → 翻身 → 看向窗户 → 短暂坐起 → 再次躺下。

## 显示目标

1. 完成三次不同的行为观察。
2. 查看一次社区求助帖并收藏一条建议。
3. 购买至少一件商品。
4. 完成一次房间布置。
5. 让 H-071 主动离开床铺。
6. 将幸福指数提升至 20。

## 隐藏目标

- 强行打扰不超过两次。
- 发现真正缺少的关键条件是光照，而不是食物。
- 拍摄 H-071 第一次使用家具的照片并发帖。
- 使用纸箱替代购买的椅子形成活动位置。

## 阶段 1：观察人类

系统提示：“新的人类已经醒了。它看起来并没有准备离开巢穴。请观察它的行为。”

| 观察对象 | 反馈 | 设计作用 |
| --- | --- | --- |
| 人类 | 已经醒来，却维持睡眠姿势；可能疲劳、寒冷、悲伤或不想起来 | 不直接给出诊断 |
| 手机 | 已检查发光方块六次，未发现从中获得食物 | 建立猫咪视角笑点 |
| 窗帘 | 完全遮光，房间仍适合夜间活动 | 指向光照线索 |
| 空桌子 | 可能用于工作、进食或堆物；缺少可坐物体 | 指向家具组合 |

完成任意三个不同观察点后，解锁“前往养人交流所寻找经验”。

## 阶段 2：猫咪社区

热门帖：**“我家人类醒了，但它拒绝离开床，该怎么办？”**

- 橘子大王：可能饿了，建议把食物放在床边。
- 黑尾研究员：检查光线，部分人类在黑暗中无法确认白天开始。
- 三花妈妈：不要一直叫，人类可能需要私人空间。
- 奶牛猫七号：买更柔软的枕头，它会更愿意起床。

玩家必须收藏一条建议。系统不标注标准答案，只提示“人类曾多次看向窗户”，让玩家自行建立观察与建议的关联。

## 阶段 3：第一次环境干预

| 操作 | 数值与反应 | 解锁 |
| --- | --- | --- |
| 拉开窗帘 | 光照提高；短暂坐起；幸福 +3 | “它注意到了阳光” |
| 反复叫醒 | 被子盖头；压力 +5；信任 -2 | 计入强行打扰 |
| 食物放床边 | 看一眼；不离床；饥饿 -5；清洁轻微下降 | 食物不是充分条件 |
| 关闭手机充电 | 立刻起身检查，三秒后躺回；信任 -3 | “人类非常重视发光方块” |

任何选择之后都得出阶段结论：改变单一条件还不够，它还需要一个愿意前往的位置。

## 阶段 4：第一次进入商店

初始资金 100 猫币。

| 商品 | 价格 | 作用 | 引导含义 |
| --- | ---: | --- | --- |
| 木制椅子 | 60 | 提高便利；与桌子形成活动区 | 新手推荐，但不强制 |
| 柔软抱枕 | 40 | 提高舒适；可能继续留床 | 数值提升不等于推进目标 |
| 小夜灯 | 50 | 提高夜间安全，白天作用低 | 情境化数值 |
| 绿色植物 | 70 | 提高审美，需要定期照顾 | 引入持续维护 |

## 阶段 5：第一次装修

木制椅子放在桌旁，形成组合“简易生活角”，生活便利 +8，解锁“坐下使用桌子”行为并提高离床概率。放在床边只会幸福 +2，并可能成为衣物架；挡住通道则幸福 -2，需要调整。

购买其他家具也能继续。若买抱枕，可把原有纸箱移到桌旁，H-071 会暂时把纸箱当椅子，从而避免唯一解。

## 自主反应与成功演出

当窗帘已拉开，且桌旁形成可用区域后触发：

1. H-071 看向窗外。
2. 拿起手机，犹豫几秒。
3. 主动离开床铺。
4. 坐到桌旁，用手机播放音乐。
5. 开始吃昨天留下的面包。

幸福指数提升至 20 以上。观察报告只写：“推测原因是阳光、家具、饥饿或它自己的决定，暂时无法确认。”避免系统抢走人类的主体性。

## 社区发帖

玩家可拍照并发布：“它今天终于离开床了。我先拉开窗帘，又在桌旁放了一把椅子。人类坐在那里吃了东西。暂时无法确认是哪种方法产生了作用。”

发帖即时奖励：猫币 +30、研究点 +5、社区经验 +10。

## 完成条件

以下条件全部满足才结束第一天：三次不同观察、查看社区帖子、购买商品、完成布置、H-071 主动离床、幸福指数达到 20。

基础奖励：猫币 +80、研究点 +10，解锁“人类生活用品”商店、“新人养人求助区”和行为图鉴“赖床”。

隐藏奖励：

- 未反复打扰：信任 +5，称号“安静的观察者”。
- 拍照发帖：小鱼干 +1，解锁相机。
- 用纸箱代替椅子：返还猫币 20，成就“猫咪的实用主义”。

## 结尾剧情

夜晚，H-071 坐在桌旁问：“你是不是一直在看着我？”

| 选择 ID | 玩家表现 | 第二天影响建议 |
| --- | --- | --- |
| `soft_meow` | 轻轻叫一声 | 信任 +1 |
| `jump_on_desk` | 跳到桌子上 | 亲近 +1，打断感 +1 |
| `pretend_not_watching` | 转身假装没观察 | 尊重空间 +1 |
| `paw_near_hand` | 把爪子放在人类手边 | 信任 +2；需较低压力 |

当日总结：“人类需要光线、可以坐下的位置，以及不会一直催促它的陪伴者。但它为什么不愿起床，仍未完全查明。”

第二天预告：**它已经盯着手机很久了。**

## 实现验收

- 玩家不能只靠反复叫醒完成任务。
- 椅子不是唯一解，纸箱路线必须可完成。
- 观察点需防止重复点击刷次数。
- 成功演出必须由环境条件触发，且标记为“主动离床”。
- 隐藏目标只在结算时揭示。
- 结尾选择写入第二天的初始关系状态。
