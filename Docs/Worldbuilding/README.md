# 世界观资料索引

## 一句话提案

在猫咪接管旧人类城市的温柔后人类时代，一只新手猫通过装修、观察和陪伴，帮助一名拒绝被“幸福指数”定义的人类重新学习生活。

## 设计支柱

1. **照顾不等于控制**：高数值、标准答案和替对方决定，并不一定构成真正的照顾。
2. **表达拒绝也是成长**：人类说“不喜欢”、移动家具或拒绝任务，可能代表自主性正在恢复。
3. **房间是情绪生态**：装修不是纯外观系统，光线、旧物、秩序和陪伴共同影响行为与记忆。
4. **温馨中带荒诞与忧伤**：猫咪认真误读人类文明，笑点服务于理解、陪伴和失去。
5. **最终目标是选择能力**：结局不是把人类永远留住，而是让它能决定离开或平等地留下。
