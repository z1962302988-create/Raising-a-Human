# 主角人类：一只停止生活的人类

## 基本档案

- 编号：H-071
- 类型：成年人类
- 状态：低响应、低活动、拒绝标准照护
- 观察所建议：重新建立规律生活，持续监测幸福指数
- 核心矛盾：想重新生活，却害怕自己的选择再次伤害别人

它没有严重身体疾病，也能说话、走路和照顾自己，却长时间躺床、反复看手机、很少主动进食、拒绝开窗帘和出门、收到消息不回复、有人靠近便假装睡着。它偶尔坐到桌前却什么也不做，并把一张旧门卡藏在抽屉深处。观察所称这种状态为“生活停摆”。

## 过去

H-071 曾在人类幸福管理局设计标准化居住环境，根据幸福指数规定房间颜色、睡眠、家具数量、社交、工作和强制干预阈值。猫咪社会广泛采用的“标准幸福房间”也有它参与设计。它相信环境足够舒适、生活足够规律，人就能够幸福。

它曾照护一名亲近的人类。对方长期低落，H-071 便不断换家具、加灯光、安排工作和聚会、移除被系统判断为负面来源的旧物，并要求对方积极起来。对方说：“我不是不想好起来。我只是希望有一次，你不要急着改变我。”H-071 没有听懂。后来对方脱离幸福管理系统，只留下“对象已脱离监测，幸福指数无法读取”。

H-071 因此意识到自己曾以照顾之名控制另一个人的生活。它不再相信自己的决定，开始拒绝选择，以为只要不选择就不会再次犯错。

## 幸福指数创伤

环境改善会让它短暂放松，但指数达到特定阶段时会触发防御：

- 30：遮住检测装置。
- 45：移走增加幸福值的家具。
- 60：可能砸坏一次显示器。

它不是害怕幸福，而是害怕再次被数字定义。指数对它而言不是关怀，而是过去工作的象征。

## 玩家为何能够靠近

之前的猫咪都追求快速提高指数，严格执行起床、开窗帘、高幸福值家具和每日任务。玩家却是新手：把纸箱当高级家具、不懂人类为何独处、不会操作监测器，有时只安静地趴在旁边，或单纯为了晒太阳拉开窗帘。

这种“不专业”让 H-071 第一次感到自己不是一个需要修复的项目。

## 第一阶段线索

1. **管理局门卡**：被藏在抽屉，看到后会立刻关上。
2. **撕掉一半的合照**：照片中有 H-071 和身份未知的人类。
3. **旧房间设计图**：与标准幸福房间完全相同。
4. **未发送的消息**：“对不起，我当时只想让你好起来。但我好像从来没有问过，你想要什么。”
5. **幸福指数屏蔽器**：证明它在主动阻止系统读取状态。

## 装修反应

标准办公桌、白色储物柜、智能睡眠灯等家具表面数值很高，却可能提高压力、降低使用率、触发记忆，甚至被它转向墙壁。

有划痕的木桌、颜色不一的椅子、旧台灯等物品基础数值较低，却使空间不像为指标设计。H-071 可能主动移动家具、留下个人物品、选择颜色，并第一次说出“我不喜欢这个”。表达拒绝本身就是恢复。

## 五阶段成长路线

1. **被动生存**：最低限度活动；让它愿意吃饭、起床和使用房间。
2. **表达拒绝**：开始反对摆设；这是自主性恢复，不应简单判为幸福下降。
3. **重新选择**：自己移动家具、购买物品、安排生活；房间变乱但真实状态改善。
4. **面对过去**：拿出门卡和旧照片。玩家可鼓励寻找旧友、劝其放下、陪它回管理局，或允许暂不决定。
5. **离开房间**：决定走出公寓；玩家必须选择打开门，或因害怕失去而试图留下它。

## 最终真相

旧友没有失踪或遇难，而是住在不受幸福指数监测的旧城区。H-071 一直知道对方可能活着，却害怕听到“我不需要你的道歉”。它需要接受：真心照顾也可能伤人；犯过错误不代表永远失去建立关系的资格。

玩家的任务不是替它选择正确人生，而是让共同生活成为一个可以慢慢选择、可以选错、可以拒绝也可以被拒绝的地方。
